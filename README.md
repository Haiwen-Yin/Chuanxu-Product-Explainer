# 川序产品交互图解

面向客户演示与产品讲解的独立动效网页，内容依据川序 v5.0.3。

直接打开 `index.html` 即可使用。七个网页、脚本、样式与品牌素材都在本目录，
不需要安装 Node.js、访问 CDN、连接数据库或配置模型。

也可在本目录启动静态服务：

```bash
python3 -m http.server 18120 --bind 127.0.0.1
```

随后访问 `http://127.0.0.1:18120/`。

## 页面与内容

| 页面 | 场景与内容 |
| --- | --- |
| `index.html` | 一次工作的流转、章节目录、12 项功能图谱 |
| `knowledge.html` | 授权检索、知识入库、记忆与上下文 |
| `collaboration.html` | 责任交接、执行图与循环、DB4A2A 共享上下文 |
| `governance.html` | 双主体授权、身份与撤销、治理与审计 |
| `runtime.html` | 请求生命周期、未知结果与恢复 |
| `integrations.html` | Skill 与工具、协议与网关 |
| `architecture.html` | 整体架构、安装与升级、三种数据库实现 |

共 15 个专题场景、90 个分步解释，以及首页的六步工作动效。
每个专题可以切换「看功能 / 看实现」，点击流程节点或步骤序号查看，
播放、暂停并以 1×、1.5×、2× 速度讲解。播放到末步后停止。

每章末尾有条件实验：知识发布条件、双主体权限交集、Worker 租约与版本、
未知请求的处理、工具调用条件、数据库原生实现。实验只改变当前网页，
不会调用业务 API 或实际发布内容。

## 演示与无障碍

- 点击「讲解模式」聚焦流程与解释，按 Esc 退出；上下章节可以接续讲解。
- 使用 Tab 访问链接、按钮、节点、开关和下拉框。
- 场景标签支持左右方向键、Home、End；流程区左右方向键切换步骤。
- 流程节点用 Enter 或空格选择，开关可用空格切换。
- 顶栏可关闭动效；选择保存在本机浏览器。系统偏好减少动态效果时默认静止。
- 关闭动效后仍可查看每一步，所有信息不依赖动画才能读取。
- 离开浏览器标签页时暂停自动推进；手机采用单列流程与说明布局。
- 浏览器打印时保留内容和流程，隐藏交互控件。

可用 `?scene=<场景名>` 直接打开场景，用 `?present=1` 进入讲解模式，例如：

```text
knowledge.html?scene=intake&present=1
runtime.html?scene=unknown
collaboration.html?scene=db4a2a
```

## 独立存放与后续维护

这是独立演示目录，没有接入官网导航、修改官网生成器、替换正式网站包或发布远程站点。
当前正式软件包、官网包、OCI 服务和数据库均不因这些网页而变化。

- `content.js`：产品内容、场景、步骤、功能与实现说明。
- `app.js`：页面渲染、SVG 流程、播放、模式和实验逻辑。
- `styles.css`：独立响应式样式、动效和减少动态效果支持。
- `assets/`：沿用川序现有品牌 SVG，未重绘字标或改变比例。
- 源目录另有 `browser_check.cjs`：本地浏览器验证脚本，只访问本地静态服务；
  `package_demo.py` 用于生成独立下载包。下载包仅含网页、运行资源与本说明。

依据资料位于主仓库：

- `build_output/v5.0.3/materials/public/whitepaper/Chuanxu-Whitepaper-zh.md`。
- `shared/docs/` 中对应的架构、知识入库、记忆、Graph、Loop、DB4A2A、
  连续工作、模型、MCP、安全、原生权限和部署指南。
- `product_delivery.py` 中的川序社区版及三种企业版定义。
- `business_plan/brand/visual_system/` 中的品牌规范与资产。

展示采用示意节点和事件，不冒充生产截图或实际执行记录。
权限、协议版本、产品类别和底座能力的限制保留在对应实现说明中，
没有添加吞吐、准确率、Token 节省或客户效果数字。
